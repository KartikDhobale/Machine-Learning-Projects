## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/KartikDhobale/Machine-Learning-Projects.git
```

### Navigate to the Repository

```bash
cd Machine-Learning-Projects
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Open Jupyter Notebook

```bash
jupyter notebook
```

Run the notebook of your desired project.
