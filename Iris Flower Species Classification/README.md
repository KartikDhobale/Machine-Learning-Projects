# Iris Flower Species Classification

## Project Overview
This project uses Machine Learning to classify iris flowers into different species based on their flower measurements.

## Dataset
The dataset used is `Iris.csv`.

It contains:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width
- Species

### Species
- Iris-setosa
- Iris-versicolor
- Iris-virginica

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Machine Learning
This is a **classification problem** where the model predicts the species of an iris flower from its measurements.

## Project Steps
1. Load the dataset
2. Explore and preprocess the data
3. Split data into training and testing sets
4. Train the ML model
5. Predict flower species
6. Evaluate the model

## Result
The trained model can predict the species of an iris flower based on its sepal and petal measurements.
